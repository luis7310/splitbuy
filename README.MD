splitbuy es una aplicacion que te permite hacer pagos compartidos, los usuarios registran una cuenta, se genera un grupo con los usuarios participantes y cada usuario puede añadir sus gastos al grupo y seleccionar los miembros del grupo que participan en dicho gasto, al final el gasto se repartirá a cada usuario con su parte que le corresponde, ya sea saldo a favor o en deuda

### Datos requeridos de los usuarios
-Id(automatico)
 -Nombre
 -Correo
 -Contraseña
 -Numero de telefono(opcional)

### Servidor 

./Backend npm install

### Entorno de pruebas
 npm run dev

 ### iniciar server 
 npm run start
